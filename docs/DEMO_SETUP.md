# Global South 시연 구성 가이드 (e-Care 멀티스크린)

시연 대상: 고객사 사장단 · 목표: 차량 경고 → 데이터 흐름 → 콜센터 → 출동 · 딜러까지 한 흐름으로, 여러 화면이 동시에 움직이는 장면.

## 1. 화면 구성 (최종 7면)

| # | 화면 | URL (릴레이 PC 기준) | 상태 |
|---|---|---|---|
| 1 | Instrument Cluster · 차량 시뮬레이터 + 컨트롤 패널 | `/` | 완료 |
| 2 | Head Unit (HU) | `/hu.html` | 다음 단계 (콜센터 · 딜러 연결) |
| 3 | Call Center Web (CCW) · 상담센터 사무실 | `/ccw.html` (CCW만: `/ccw.html?view=app`) | 완료 |
| 4 | 상담 대화 텍스트 | `/ccw.html?view=transcript` | 완료 |
| 5 | Data Flow Monitor | `/flow.html` | 예정 |
| 6 | Operation Web (OPW) · 설정값 조작 | `/opw.html` | 예정 |
| 7 | DMS · 딜러 시스템 | `/dms.html` | 예정 |

모든 화면은 같은 동기화 채널(`js/link.js`)을 씁니다. 차량 시뮬레이터가 시나리오의 기준(director)이고, 다른 화면은 상태를 받아 그리고 버튼 조작은 명령으로 되돌려 보냅니다.

## 2. 권장 방식: PC 1대(메인) + 필요 시 PC 1대(보조), 유선

**A안 (권장) — 고성능 PC 1대 + 다중 출력**
- 데스크톱 1대(RTX 4070급 GPU, DisplayPort/HDMI 4~6출력 또는 MST 허브), 각 TV에 브라우저 창을 하나씩 전체화면으로 띄움.
- 동기화는 같은 브라우저 안의 BroadcastChannel → **네트워크 없이** 0ms 수준으로 동기화. 무선 장애 · 방화벽 · 행사장 망 정책 영향이 없음.
- Chrome을 `--kiosk` 또는 창별 F11 전체화면, 각 창을 해당 모니터로 이동.

**B안 — 화면별 PC(또는 미니PC) + LAN 릴레이**
- 메인 PC에서 `node tools/relay.mjs` 실행 → `http://<메인PC IP>:8787/…`을 각 PC 브라우저에서 엶. 페이지가 릴레이를 자동 감지하여 LAN으로 동기화.
- 같은 서브넷, 유선 기가비트 스위치(8포트) 권장. 무선은 백업으로만.
- 포트 8787(TCP) 인바운드 허용, 모든 PC 같은 포트/주소 사용.

**C안 — 인터넷 공개 주소만 사용 (비권장)**
- Vercel 주소는 같은 브라우저 창끼리만 동기화. 여러 PC 간 동기화는 A/B안 필요.

## 3. 장비 목록 (7면 기준, A안)

| 항목 | 수량 | 비고 |
|---|---|---|

| UPS | 1 | 메인 PC · 스위치 |

## 4. 시연 진행 (약 6분)

1. **시동** — 컨트롤 패널 `I` → "Welcome to Global South 개발 진척 보고회" 오프닝.
2. **주행** — `Space` 출발 → 커브 · 시가지 주행, 계기판 3D 시티 내비.
3. **긴급 경고** — `W` 브레이크 경고 → 계기판 경고등 · CCW에 긴급 케이스 접수(SLA 25:00 시작).
4. **25분 경과** — `T` → 인바운드 콜 없음 → 유휴 상담사 자동 배정 → CCW 경고 알림 팝업(05:00, 1분 미만 빨간색 · 알림음).
5. **전화 걸기** — CCW 팝업 [전화 걸기] 또는 `A` → e-Care 고객 응대 화면, 상태바 발신중 → 상담중 → 차량 갓길 정차 · 통화(녹음 음성) · 대화 화면 실시간 · 계기판 "e-Care 상담센터 통화 중".
6. **긴급출동** — 통화 중 자동 요청(또는 `E`) → 신고접수 → 출동 → 도착 → 출동완료, CCW 지도에 출동 차량 이동.
7. **상담 메모 · 이관** — 통화 종료 → 후처리중 → 상담정보 바텀시트(상담 메모 → 서비스센터 선택 → 상담내역 확인) → 저장 · DMS 전송 → 이관 완료(또는 `K`로 한 번에).
   - 변형 A: `G` 고객 전화(인바운드) → 전화 수신 안내 팝업 [확인] → 바로 상담.
   - 변형 B: `U` 고객 미응답 ON → 3회 발신 실패(재연결 대기 01:00은 `T`로 건너뛰기) → SMS 자동 발송 완료 → 상담 메모.
8. **초기화** — `R` (e-Care) · `X` (경고등) · `I` (시동 OFF → "See you soon").

## 5. 운영 팁

- 리허설 2회 이상, 시연 전 모든 화면을 한 번 클릭(브라우저 자동재생 정책으로 통화 음성 · 주변 소음이 막히지 않게).
- 콜센터 주변 소음은 상담원 화면 PC 스피커로만 나옵니다. 통화 음성이 잘 들려야 하는 구간에서는 `L`로 끌 수 있습니다.
- 절전 · 화면보호기 · OS 업데이트 · 알림 끄기, 브라우저 확장 프로그램 없는 전용 프로필.
- 오프라인 대비: 저장소를 메인 PC에 받아 `node tools/relay.mjs`로 로컬 실행(인터넷 불필요, 웹폰트만 기본 글꼴로 대체됨).
- 예비 PC에 같은 구성을 미리 띄워 두고, 장애 시 HDMI 스위처로 전환.

## 6. 아이패드(무선)로 상담 대화 화면 띄우기

1. 메인 PC에서 `node tools/relay.mjs` 실행 → 콘솔에 표시된 `transcript` 주소 확인 (예: `http://192.168.0.10:8787/ccw.html?view=transcript`).
2. 아이패드를 메인 PC와 **같은 Wi-Fi**에 연결 → 크롬에서 위 주소 열기. 우측 하단이 `● 차량 연결됨 · LAN`이면 동기화 중.
3. 메인 PC의 차량 · 상담원 화면도 **같은 릴레이 주소**(`http://192.168.0.10:8787/…`)로 열어야 합니다. `localhost`나 Vercel 주소로 연 창은 아이패드와 동기화되지 않습니다.
4. 처음 접속 시 iPadOS가 "Chrome이 로컬 네트워크의 기기를 찾으려고 합니다"를 물으면 **허용** (설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → Chrome ON).
5. 화면을 한 번 탭하면 화면 꺼짐이 방지됩니다. 확실하게 하려면 설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함, 손님용으로는 손쉬운 사용 → 사용법 유도된 접근으로 크롬 고정.

안 될 때: 행사장 · 게스트 Wi-Fi는 기기 간 통신을 막는 경우가 많습니다(AP/클라이언트 격리). 시연용 공유기(또는 노트북 핫스폿)를 따로 두고, 메인 PC는 유선, 아이패드만 그 공유기의 Wi-Fi에 붙이세요. Windows는 처음 실행 시 방화벽 창에서 Node.js의 **개인 네트워크** 접근을 허용해야 합니다(포트 8787).

## 7. 대강당 3면 스테이지 (300인치급 × 3)

| 스크린 | 주소 | 내용 |
|---|---|---|
| 왼쪽 | `/stage.html?screen=left` | 고객 · 차량 (운전석 · 계기판 · HU) |
| 가운데 | `/stage.html?screen=center` | 데이터 흐름 모니터 + 통화 자막 |
| 오른쪽 | `/stage.html?screen=right` | 콜센터 사무실 · 상담원 화면 |
| 진행자 | `/remote.html` | 태블릿 리모컨 (단계 · 멘트 · 수동 조작) |

- 송출 PC 1대(3출력)면 크롬 창 3개를 각 출력에 전체화면(`F`). 소리가 클릭 없이 나오도록 크롬을 `--autoplay-policy=no-user-gesture-required --kiosk` 옵션으로 실행하고, 창마다 `--new-window --user-data-dir`를 다르게 주면 편합니다.
- 모든 주소는 릴레이(`node tools/relay.mjs`) 기준. 리모컨 태블릿은 같은 네트워크에서 `/remote.html`.
- 차량 시뮬레이터(시나리오 기준)는 왼쪽 스크린 안에서만 실행합니다. 같은 시점에 `index.html`을 다른 창으로 또 열지 마세요.
- 리허설: 한 모니터에서 `/stage.html?screen=all` + `/remote.html`.
- 월요일 현장 확인 후 맞출 것: 화면 비율 · 입력 해상도, 3면이 분리형인지 연결형(엣지 블렌딩)인지, 음향 입력, 진행자 위치, 객석 거리(글자 크기).
