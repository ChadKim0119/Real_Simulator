# 단축키 · Ulanzi D200X 키 데크 구성

컨트롤 패널(`control.html`)과 Final 두 화면(`final_instrument.html` · `final_dataflow.html`)은 같은 단축키를 씁니다.
세 창 중 **어느 창에 포커스가 있어도** 같은 동작을 합니다. Final 화면에서 누른 키는 같은 PC의 컨트롤 패널로 전달됩니다.
다른 PC에 열린 컨트롤 패널은 움직이지 않고, 같은 브라우저에 컨트롤 패널이 둘이면 마지막으로 쓴 쪽만 반응합니다.
컨트롤 패널에서 `?`(Shift + /)를 누르면 키 목록이 뜹니다.

## 키 목록

| 키 | 동작 |
|---|---|
| → ↓ Space PageDown | 다음 단계 |
| ← ↑ PageUp | 이전 단계 |
| A | 자동 진행 켜기 · 끄기 |
| Shift + R | 초기화 (확인 없이 바로) |
| 1 · 2 · 3 | 창 열기 · 앞으로: 컨트롤 · 계기판 HU(Final_Instrument) · 데이터 흐름(Final_Dataflow). 지금 창의 번호면 전체화면 |
| F | 지금 창 전체화면 켜기 · 끄기 |
| O | 오프닝 켜기 · 끄기 |
| L · C · E · B | 장면: 라이브 · 클로징 · 종료 · 암전 |
| 4 · 5 · 6 · 7 | 차량 시점: 자동 · 전체 · 계기판 · HU |
| [ · ] | 차량 시점 이전 · 다음 (노브용) |
| 8 · 9 · 0 | 고객지원실 화면: 자동 · 화면만 · 사무실 |
| H | 비상등 |
| D | 데이터 흐름 상세 보기(Q&A) 켜기 · 끄기 |
| T | 상담 대화 패널 펼치기 · 접기 |
| Shift + 1 ~ 6 | 시나리오 선택: 전체 발표 · 고객 전화 · 상담원 발신 · 미응답 SMS · 서비스센터 직행 · 일반 전화 |
| ? | 키 목록 (컨트롤 패널) |

- Ctrl · Alt · ⌘ 가 붙은 키는 브라우저 몫으로 남겨 둡니다.
- 입력칸에 커서가 있으면 단축키는 동작하지 않습니다.
- 물리 키 위치로 읽으므로 한글 입력 상태여도 같습니다.
- Final_Dataflow가 상세 보기(D) 중일 때 그 창에서 누른 화살표 · Space는 상세 보기의 단계 이동으로 동작합니다(Q&A용). 시나리오 진행은 컨트롤 · Final_Instrument 창에서 하세요.

## D200X 구성안 (키 14개 · 노브 3개 · 버튼 2개)

D200X의 키는 5열 × 3행이고, 오른쪽 아래 한 칸은 2칸 너비의 넓은 키(시계 · 시스템 정보 창)입니다.
키 아이콘(196×196 PNG)은 `tools/ulanzi/icons/`에 있습니다.

**Page 1 · 시연 진행** (FigJam 작업판에서 정한 배치)

| | | | | |
|---|---|---|---|---|
| 계기판 · HU 창 `2` | 데이터 흐름 창 `3` | 컨트롤 창 `1` | 자동 진행 `A` | 초기화 `Shift+R` |
| 오프닝 `O` | 클로징 `C` | **PAGE 1** (누르면 Page 2) | 시점 자동 `4` | 시점 전체 `5` |
| 이전 `←` | 다음 `→` | (빈 칸) | 넓은 키: 로고 | ← |

**Page 2 · 장면 · Q&A**

| | | | | |
|---|---|---|---|---|
| 데이터 화면 상세 · 심플 `D` | 상담실 자동 `8` | 상담실 화면만 `9` | 상담실 사무실 `0` | 초기화 `Shift+R` |
| 키 목록 `?` | 상담원 발신 `Shift+3` | **PAGE 2** (누르면 Page 1) | 고객 전화 `Shift+2` | 미응답 → SMS `Shift+4` |
| 이전 `←` | 다음 `→` | 상담 대화 `T` | 넓은 키: 로고 | ← |

- 가운데 키는 지금 페이지 번호를 보여 주고, 누르면 다른 페이지로 넘어갑니다. 아래 줄 버튼 2개도 이전 · 다음 페이지입니다.
- 이전 · 다음은 두 페이지 모두 왼쪽 아래(0_2 · 1_2)입니다. 넓은 키(3_2)는 배경 이미지(로고, 392×196)를 보여 줍니다. 로고 파일은 공개 저장소에 두지 않고 `tools/ulanzi/icons/local/wide-logo.png`에 둡니다.
- 노브 3개는 사운드 크기입니다. 볼륨 동작은 파일에 넣을 수 없어(내부 ID 미확인) Ulanzi Studio에서 노브마다 시스템 → 볼륨을 끌어다 놓습니다.
- ‘데이터 화면 상세 · 심플’은 `D`(Final_Dataflow 심플 ↔ 상세)입니다.
- 데크에 없는 키는 키보드로 누릅니다: 라이브 `L`, 암전 `B`, 종료 `E`, 비상등 `H`, 시점 확대 `6` `7`, 시점 이전 · 다음 `[` `]`, 전체화면 `F`, 시나리오 `Shift+1` `Shift+5` `Shift+6`.

## 프리셋 파일 (.ulanziDeckProfile)

위 두 페이지와 아래 버튼 2개(이전 · 다음 페이지)를 담은 Ulanzi Studio 프리셋입니다. Ulanzi Studio의 **Import Local Preset**으로 불러옵니다.

- 형식은 Ulanzi Studio(macOS)가 내보낸 실물 프리셋을 기준으로 맞췄습니다.
  - 파일 구조: `#Version: 2` 줄 뒤에 ZIP이 붙습니다.
  - 키 · 노브 · 버튼 칸: 행 0~2가 LCD 키, 행 3이 아래 줄(`0_3` · `1_3` 버튼, `2_3`~`4_3` 노브)입니다.
  - 단축키 표기: `⇧ R`, `→`
- 프리셋에는 D200X 기기 UUID가 들어가므로 공개 저장소에는 파일을 올리지 않습니다. 생성기로 만듭니다.
  ```
  python3 tools/ulanzi/build_profile.py --device <기기 UUID> --out RealSimulator_D200X.ulanziDeckProfile
  ```
  기기 UUID는 Ulanzi Studio에서 내보낸 아무 프리셋의 `manifest.json` → `Device.UUID`에 있습니다.
- 키 배치를 바꾸려면 `tools/ulanzi/build_profile.py`의 `PAGES` · `KNOBS` 표를 고칩니다.
- 넓은 키(`3_2`)는 배경 모드로 둡니다. 시계로 바꾸려면 Ulanzi Studio에서 지정합니다.

**노브 · 버튼**

| 조작 | 지금 배치 |
|---|---|
| 노브 1 · 2 · 3 | 사운드 크기 (Ulanzi Studio에서 볼륨 동작 지정) |
| 버튼 2개 | 페이지 1 ↔ 2 전환 |

## Ulanzi Studio 설정 순서

1. Ulanzi Studio를 설치하고 D200X를 연결합니다. 설정한 동작은 Ulanzi Studio가 실행 중일 때만 동작합니다.
2. 프로필을 하나 만들고 페이지를 2개 둡니다.
3. 각 키에 **단축키(Hotkey)** 동작을 넣고, 위 표의 키를 입력합니다. `Shift+R`처럼 조합키는 Shift를 함께 누른 상태로 입력합니다.
4. 키 아이콘에 `tools/ulanzi/icons/`의 PNG를 지정합니다.
5. 노브 3개에는 시스템 → 볼륨 동작을 끌어다 놓습니다.
6. 시연 전, 컨트롤 패널이나 Final 화면 중 한 창을 한 번 클릭해 포커스를 둡니다. D200X는 지금 포커스가 있는 프로그램으로 키를 보내므로, 발표 PC에서 다른 프로그램(파워포인트 등)이 앞에 있으면 그 프로그램이 키를 받습니다.

Ulanzi Studio의 메뉴 이름은 버전에 따라 다를 수 있습니다. D200X는 Stream Deck 플러그인과 호환되지 않으므로 Ulanzi Studio 기본 단축키 동작을 씁니다.
