# Real Simulator — Lexus GX 인스트루먼트 클러스터 주행 시뮬레이터

GX 실내 사진 3장(핸들 포함 · 핸들 제거 · 핸들 단독, `assets/src/`)을 기반으로 만든 인터랙티브 계기판 시뮬레이터입니다.
핸들 제거 사진을 배경판으로, 핸들 단독 사진을 회전 레이어로 쓰고, 12.3" 클러스터(디자인 기준: `assets/gx_cluster.jpg`)는 모든 표시를 실시간 렌더링합니다.

## 실행

`index.html`을 브라우저에서 바로 열거나, 로컬 서버로 실행합니다.

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## 동작

- **시동 ON**: 매번 “Welcome to / Global South / 개발 진척 보고회” 오프닝 — 수평선이 열리고 빛줄기 · 불꽃이 퍼지며 글자가 한 자씩 떠오르고 금빛 광택이 지나간 뒤 플래시와 함께 계기판으로 전환(차임 아르페지오). 이어 경고등 점검 · 타코미터 스윕. 화면 중앙에 “시뮬레이터 화면으로 실제 차량의 화면과는 다를 수 있습니다.” 안내가 잠깐 표시됩니다.
- **시동 OFF**: 계기판이 사라지며 “See you soon” 작별 화면 → 수평선이 한 점으로 모여 꺼짐(하강 차임).
- **출발**: P→D, 10단 자동변속으로 가속 후 어시스턴트 주행. 교통 흐름 · 경사에 따라 속도가 약 60~84 km/h 사이에서 변하고 커브 앞에서는 감속합니다.
  처음에는 사진과 같은 전체 화면이 보이다가 **3초 뒤 카메라가 계기판으로 천천히 줌인**하고 핸들은 반투명해집니다.
- **정지**: 감속 → 정차 후 P → 원래 시점으로 복귀. 차가 서면 핸들은 약 2초에 걸쳐 부드럽게 정중앙으로 돌아가 멈춥니다.
- **경고 / 주의**: 경고(빨강) 6종 · 주의(주황) 6종이 클러스터 상단 고정 위치에 점등되고, 중앙 메시지와 경고음이 출력됩니다. 정속 주행 시 녹색 ACC · 크루즈 · 차선 표시등이 켜집니다.
- **클러스터**: 디지털 속도 · 기어(D + 실제 단수, 변속 시 ▲/▼ 표시) · 외기온 · 시계(보는 기기의 현재 시각, AM/PM) · 나침반 방위, 엔진 회전수 디지털 표시, 좌측 타코미터 아크(레드존), 우측에는 GX 탑뷰 메시(앞바퀴 조향 각도와 예상 진행선이 실시간으로 움직임, 바퀴별 타이어 공기압, 핸들 · 바퀴 각도, 드라이브 모드)와 G-미터, 음악 재생 정보(하단 중앙, 테두리 없이 · 느린 마키 · 진행 시간, A2O LITE ‘NEON’), 냉각수온 · 연료 바, 주행거리, 주행가능거리, ECO 표시.
  가운데는 **헤딩업 3D 야간 시티 내비**: 원근 카메라로 그린 건물(불 켜진 창, 지붕 설비, 달빛 음영), 공원과 나무, 보도 · 골목 · 횡단보도, 차선이 있는 도로와 파란 경로, 가로등, 랜드마크(서비스센터 · 상담센터 · 데이터센터) 이름판. 톤&매너는 [connected-car 시뮬레이터](https://simulator-connectedcar.vercel.app/)의 도시를 실사풍으로 옮겼습니다. 다음 교차로 · 커브 안내, 도로명, 제한속도, 속도에 따른 자동 축소.
- **도시 동기화**: 도시 블록(`Road.city`)이 도로 모델에서 결정되어 계기판 지도와 앞유리 풍경에 같은 건물 · 공원이 나타납니다. 시가지와 교외 구간이 번갈아 나옵니다.
- **외부 풍경**: 앞유리와 옆 유리 너머로 산길 2차선 지방도가 보입니다. 직선 · 완만한 커브 · 급커브(최소 R≈127 m) · S자 구간이 이어지고, 커브 바깥쪽 갈매기 표지 · 가드레일, 커브 전 주의 표지, 가로수 · 전신주 · 대향차가 주행과 함께 움직입니다. 커브에서는 먼 산과 숲이 옆으로 흘러갑니다.
- **커브 주행**: 출발 직후 약 70 m 지점부터 커브가 시작됩니다. 어시스턴트가 앞의 커브를 보고 미리 감속했다가 빠져나오며 다시 가속합니다. 계기판 안내창에 커브 방향 · 남은 거리 · 권장 속도가 표시됩니다. 핸들만 곡률에 맞춰 돌고 방향지시등 · 와이퍼 레버 · 컬럼 커버는 고정됩니다. 핸들은 정면 사진을 WebGL 메시로 그려, 핸들 평면 안에서 회전시킨 뒤 원근(림은 림 외곽에 맞춘 호모그래피, 허브는 허브에 맞춘 호모그래피, 스포크는 그 사이 보간)으로 투영하므로 접시 모양 핸들처럼 돌아갑니다. 최대 약 ±22°로 스포크가 계기판을 가리지 않습니다.
- **동기화**: 하나의 도로 모델(`js/road.js`)이 앞유리 밖 커브, 미니맵 회전, 핸들 조향각(곡률 × 조향비)을 함께 결정합니다.
- **사운드**: 고급 SUV 콘셉트 — 차음이 잘 된 실내로 들리는 부드러운 V8(저차 오더 중심, 하프 · 1.5 오더의 은은한 버블), 짧고 절제된 스타터와 시동 순간의 낮은 울림, 조용한 타이어 · 노면 · 풍절음, 경고 비프 · 안전벨트 반복 차임 · 주의 차임 · 웰컴 차임.
- 핸들은 도로 곡률에 맞춰 돌고 미세한 보정 조향이 더해지며, 주행 중에는 그림자와 빛이 은은하게 실내를 지나갑니다.

## 대강당 3면 스테이지 · 데이터 흐름 모니터

- **데이터 흐름 모니터** (`flow.html`): 차량 → VDP → VEP(필터 · WNG master Case 판정) → WAM → 콜센터 CCW · CTI · 딜러 DMS · 긴급출동 · SMS · 고객 앱/HU. 모든 메시지를 실제 인터페이스 이름(WAM-EVT-001, WAM-SLA-001, WAM-MEMO-001, DMS-SVC-002 …)과 함께 패킷으로 표시, Case 판정 카드, 워크플로우 ID · SLA 링, 이벤트 로그, 통화 자막, 25분 경과 연출. 1920×1080 기준 SVG라 어떤 해상도로도 선명하게 늘어남.
- **3면 스테이지** (`stage.html?screen=left|center|right`): 왼쪽 고객 · 차량(`index.html?stage=1`), 가운데 데이터 흐름, 오른쪽 콜센터(`ccw.html?stage=1`). 오프닝 · 클로징(시연 KPI · 타임라인 · 연동 시스템)은 3면에 이어지는 파노라마. `?screen=all`은 한 모니터에서 3면 리허설. 스테이지 PC에서 `F` 전체화면, `I` 화면 확인.
- **고객 헤드유닛** (`hu.html`): 고객 차량 멀티미디어 화면. 경고 시 WNG master 문구의 e-Care 팝업(Case A “고객 지원실로 연결하시겠습니까?” [전화연결] / Case B·C “지정된 서비스센터로 연결하시겠습니까?”, v8.2 멀티미디어 안내문구), [전화연결] → MM 인바운드 콜(CTI → 유휴 상담원 배정 · 25분 자동 아웃바운드 취소), 통화 화면 · 긴급출동 배너 · 상담 완료/딜러 상태 카드, 아웃바운드 때는 고객 휴대전화(수신 · 통화 · SMS)가 들어옴. 통화 자막 포함. 무대 왼쪽 화면에서 경고가 뜨면 자동으로 HU 전체 + 계기판 PIP로 전환.
- **진행자 리모컨** (`remote.html`, 태블릿): 메인 시나리오 15단계 — 오프닝 → 시동 → 주행 → **1막 고객 인바운드**(브레이크 경고 HU 팝업 → 주행 중 HU [전화연결] → 상담원 받기 → 통화 약 70초 · 통화 중 갓길 정차 → 완료 · 이관) → **2막 상담원 아웃바운드**(다시 경고 · 고객 미연락 → 25분 경과 → 전화 걸기 → 완료 · 이관) → Case B 비교 → (OPW) → 시동 끄기 → 클로징. 단계별 발표 멘트, `→`/Space 다음, 수동 조작(장면 · 왼쪽 화면 자동/계기판/HU · HU 전화연결 · 상담원 받기 · 경고 Case A/B/C · e-Care · 전체 초기화).
- 경고등은 WNG master for e-Care v7 기준 코드 · Case로 판정(브레이크 BRW A, 냉각수 WTPW A, 에어백 FSRS B, 브레이크 패드는 시뮬레이터 가정 C). Case B/C는 상담원 없이 DMS로 직행.

## e-Care 콜센터 시뮬레이터 (멀티스크린)

- **상담원 화면** (`ccw.html`): 실사 상담센터 사무실 사진의 모니터에 CCW 웹(1920×960)을 실시간으로 띄웁니다. 사무실 → 상담원 화면 확대(주변 사무실이 함께 보이게), `V`로 전환. `ccw.html?view=app`은 상담원 화면만 전체 화면으로 표시(TV 한 대에 CCW만 띄울 때).
  Global South Call Center Web 규격서 · GUI(Figma `로컬앱_최신본` 1.CCW) 기준:
  - 11.1.1.2 경고 알림 팝업: 25분간 인바운드 콜 없음 → 유휴 상담사 자동 배정 → 05:00 카운트다운, 1분 미만 빨간색 + 경고 알림음, 00:00 이후 초과 시간(+00:01…) → [전화 걸기]
  - 11.1.1.1 전화 수신 안내 팝업: 고객 인바운드(MM 콜) → [확인]
  - 11.2.1.1 e-Care 고객 응대: 상태바(발신중 · 상담중 · 후처리중 · 상담 대기, 전화 끊기 · 보류 · CTI 연결/해제), 차량 · 고객 정보, 고객 차량 위치(최초 고장 발생 위치 · 마지막 수신 위치, 실시간 지도), 차량 경고 정보(MID 메시지 · 고객 안내 문구), 경고등 이력 · 상담 이력, 긴급 출동(신고접수 → 출동 → 도착 → 출동완료)
  - 예외 A 3회 발신 실패: 남은 대기 시간 01:00 → [전화 재연결] → 재시도 2/2 실패 → SMS 자동 발송 완료 → 상담 완료
  - 11.3.1.x 상담 메모 바텀시트: 상담 제목 자동 입력(긴급상담건_고객명_날짜) · 상담 내용 · 서비스 센터 전달 ON/OFF → 서비스센터 선택(업무중만 보기) → 상담내역 확인 → 저장 · DMS 전송 → 이관 완료, 서비스센터 처리 상태(컨택대기 → 컨택 → 예약 …)
  - 콜센터 주변 소음(웹오디오로 생성: 공조 소음, 멀리서 들리는 상담원 목소리, 키보드, 전화벨): `N` 또는 [주변 소음 끄기], 차량 컨트롤 패널 [콜센터 소음] `L`
- **첫 화면**: 11.4.1.1 고객 상담 이력(조회 조건, 상담 목록, 상세보기 → 상담이력 상세 · 추가 메모). 컨택 전 긴급 건은 [고객 상담 진행]으로 바로 발신.
- **고객 전화** `G`: 경고 케이스가 있으면 11.1.1.1 전화 수신 안내 팝업, 없거나 이미 끝났으면 11.1.1.3 일반 전화 팝업([전화 받기] → 상담중 → 통화 후 상담이력 상세에 추가 메모).
- **대화 화면** (`ccw.html?view=transcript`, 아이패드 · TV용): 실시간 대화(대화를 탭하면 편집 · 삭제, 모든 화면에 동기화), 대화 스크립트 탭(다음 통화 대사 편집 · 추가 · 삭제 · 초기화, 차량 PC에 저장).
  - **대화 상황(세트) 선택**: 고객 인바운드는 세트 1(빨간 경고등 · 차분한 고객, 남성 상담원 v4)과 세트 2(엔진 이상 · 긴박한 고객, 여성 v4) 중 선택. 스크립트 탭 상단 또는 리모컨 ‘대화 상황’에서 고르며 다음 통화부터 적용, 리모컨 경고 단계는 세트에 맞는 경고등(브레이크 / 엔진)을 띄움. 통화 중 고객이 정차했다고 말하는 대사(`stop`)에서 차가 갓길에 섬.
  - **음성 세트**: 시나리오(인바운드 · 아웃바운드 · 일반 전화)마다 `상담원 음성` · `고객 음성` · `대화 전체` 파일(MP3/WAV/M4A)을 올리면 대사 사이 쉬는 구간(긴 순서로 대사 수 − 1개)에서 자동으로 잘라 각 대사에 붙임. 파형에서 경계선을 끌어 조정, 구간별 미리듣기, 대사별 개별 파일도 가능. 대사 길이가 통화 진행 타이밍이 됨. 릴레이로 실행하면 `assets/audio/user/`에 저장되어 모든 화면에서 재생, 릴레이 없이면 그 브라우저(IndexedDB)에 저장.
- **컨트롤 패널(하단)** e-Care 콜센터: 상담원 화면 띄우기 `O` · 대화 화면 `Y` · 고객 전화(인바운드) `G` · 25분 경과(재연결 대기 건너뛰기) `T` · 상담원 전화 걸기 `A` · 긴급출동 `E` · 완료 · 이관 `K` · 고객 미응답(3회 발신 실패) `U` · 콜센터 소음 `L` · 시나리오 초기화 `R`.
- **동기화** (`js/link.js`): 같은 PC의 브라우저 창끼리는 BroadcastChannel로 자동 동기화. 여러 PC는 `node tools/relay.mjs`(의존성 없음)를 실행하고 각 PC에서 `http://<IP>:8787/…`로 열면 LAN으로 동기화됩니다. 차량 시뮬레이터가 시나리오 기준(`js/ecare.js` Director).
- 시연 장비 · 화면 구성 가이드: [`docs/DEMO_SETUP.md`](docs/DEMO_SETUP.md)
