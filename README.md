# Real Simulator — 인스트루먼트 클러스터 주행 시뮬레이터

첨부 사진(`assets/source.jpg`)을 기반으로 만든 인터랙티브 계기판 시뮬레이터입니다.
사진을 레이어(대시보드 · 핸들 · 앞유리)로 분리하고, 계기판 화면은 실시간으로 렌더링해 사진의 검은 유리 위에 합성합니다.

## 실행

`index.html`을 브라우저에서 바로 열거나, 로컬 서버로 실행합니다.

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## 조작 (터치 · 마우스 · 키보드)

| 기능 | 버튼 | 키 |
| --- | --- | --- |
| 시동 ON / OFF | ENGINE START STOP | `I` / `Enter` |
| 출발 | 출발 | `D` / `↑` |
| 정지 | 정지 | `S` / `↓` / `Space` |
| 경고등 (빨강) 발생 | 경고 | `W` |
| 주의등 (주황) 발생 | 주의 | `C` |
| 경고등 해제 | 경고 해제 | `X` |
| 시점 전환 (전체 ↔ 계기판) | 시점 전환 | `V` |
| 소리 / 전체화면 / UI 숨기기 | 하단 칩 | `M` / `F` / `H` |

## 동작

- **시동 ON**: 백라이트 점등 → 경고등 전구 점검 → 바늘 스윕 → 스타터 크랭킹 후 공회전(약 760 rpm).
- **출발**: 기어 P→D, 8단 자동변속(변속 시 rpm 하강)으로 100 km/h까지 가속 후 어시스턴트 정속 주행.
  처음에는 사진과 같은 전체 화면이 보이다가 **3초 뒤 카메라가 계기판으로 천천히 줌인**하고, 핸들은 부드럽게 투명해지며 사라집니다.
- **정지**: 감속 → 정차 후 P 단 → 카메라가 원래 시점으로 복귀하고 핸들이 다시 나타납니다.
- **경고 / 주의**: 누를 때마다 다음 경고등이 계기판 상단(경고, 빨강)·하단(주의, 주황)의 고정 위치에 점등되고, 중앙에 안내 팝업과 차임이 출력됩니다.
- 핸들은 항상 미세하게 움직이며 주행 중에는 보정 조향이 커집니다. 차선 · 가로수 · 가드레일 · 대향차 등 외부 요소와 지도, 주행거리, 잔여 주행가능거리, 연료량이 모두 속도에 동기화됩니다.

## 구조

```
index.html
css/style.css
js/icons.js      경고등 벡터 아이콘
js/cluster.js    계기판 렌더러 (바늘, 숫자, 지도, 경고등, 팝업)
js/exterior.js   앞유리 밖 도로 장면
js/audio.js      엔진·스타터·노면·차임 사운드 (Web Audio)
js/sim.js        차량 상태, 물리, 변속, 카메라, 입력
assets/          source.jpg(원본), dash.webp / wheel.webp(분리 레이어)
tools/build_layers.py  원본 사진에서 레이어를 다시 생성하는 스크립트
```

레이어 재생성: `pip install pillow numpy scipy opencv-python-headless && python3 tools/build_layers.py`
